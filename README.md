# Invoice Manager

Enterprise-oriented invoice management platform designed for SMEs, built with **ASP.NET Core MVC**.

The application enables companies to manage clients, invoices, payment tracking and financial visibility through a business-focused dashboard and operational workflow.

---

## Features

✔ Client Management

✔ Invoice CRUD Operations

✔ Automatic Invoice Status Tracking
(Pending / Paid / Overdue)

✔ Financial Dashboard & KPI Overview

✔ Search & Dynamic Filtering

✔ Invoice Detail View

✔ PDF Export / Print Support

✔ Business Workflow Monitoring

## Installation

Clone repository:

```bash
git clone https://github.com/TU-USUARIO/invoice-manager-dotnet.git
```

Navigate into project:

```bash
cd invoice-manager-dotnet
```

Restore dependencies:

```bash
dotnet restore
```

Run application:

```bash
dotnet run
```
